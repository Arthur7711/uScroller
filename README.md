# uScroller — YouTube Shorts Auto Scroll

A Chrome/Edge extension that moves to the next YouTube Short for you.

## Install
1. Open `chrome://extensions` (or `edge://extensions`).
2. Turn on **Developer mode**.
3. Click **Load unpacked** and pick this `uScroller` folder.
4. Open https://www.youtube.com/shorts and it starts scrolling.

## Features
- **Short ends** mode: scrolls when the current short finishes (with an optional delay).
- **Every N seconds** mode: scrolls on a fixed timer.
- Skips sponsored/ad shorts (optional).
- Counts how many shorts it has scrolled.
- **Alt+S** on the page toggles it on/off.

Settings are in the extension popup (toolbar icon).
